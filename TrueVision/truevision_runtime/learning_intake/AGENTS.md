# TrueVision media-learning intake instructions

**DO NOT CREATE A NEW WORKFLOW UNTIL THE EXISTING ENTRYPOINT HAS BEEN TRACED.**

## Scope and parent

Read the root, `TrueVision/AGENTS.md`, and `TrueVision/truevision_runtime/AGENTS.md`.
This package handles selected visual source-state learning and profiles; it is
not DocuFilm document/glyph intake.

## Production entrypoint and allowed operations

Code-defined families include `source_surface.py` capture planning and video
state receipt, `meter_grid.py` native capture profiling,
`element_creation_profile.py` creation signatures, `batch_queue.py` queued
source work, and `youtube_cdp.py` browser DevTools calls. Trace the selected
caller and approval path before external fetch or browser control.

## Forbidden operations and authority boundary

Do not treat a source candidate, search result, capture plan, or learning
profile as an approved/observed video. Do not run CDP actions merely because
the helper is callable. This package does not acquire TrueVisionIntake's
document authority or bypass the root system route.

## Inputs, outputs, receipts, and provenance

Keep approved source identity, URL/path, capture timing, native state path,
profile hash, video-state verification, and receipts. Check the specific
function's result and persisted files before calling an intake complete.

## Known staged paths and next contract

Trace the selected module's caller, source admission, return branch, and
runtime receipt before claiming intake occurred.
