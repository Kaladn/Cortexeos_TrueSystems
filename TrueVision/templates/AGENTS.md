# TrueVision template instructions

**DO NOT CREATE A NEW WORKFLOW UNTIL THE EXISTING ENTRYPOINT HAS BEEN TRACED.**

Read the root and `TrueVision/AGENTS.md`. Template files are render inputs,
not completed media. Check the selected parser and allowed visual mode in
`truevision_runtime/rendering/template_renderer.py` before execution. Keep the
source template and audio paths, then verify the returned media, state log,
manifest, and receipt.
