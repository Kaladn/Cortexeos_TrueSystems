# Generic Question Pressure Compiler

Status: production contract.

The compiler constructs a traversal request only from:

1. the exact incoming question;
2. the temporary TrueVision question compilation;
3. the admitted dataset lexicon;
4. generic TrueMem pressure and traversal laws.

It must never receive an expected answer, expected block, expected path,
benchmark identity, question ordinal, or corpus-specific transition hint.

## Construction

- One complete admitted named structure becomes the initial ruling center.
- Structures nested inside an exact date remain constraints rather than
  competing ruling identities.
- The structurally richest complete named structure wins; question position is
  the deterministic tie break.
- Exact admitted dates become structure obligations.
- Alias questions become explicit-alias obligations.
- Otherwise, admitted content anchors surrounding the final interrogative form
  independent exact context obligations.
- Transition context consists only of admitted content and relation anchors
  present in the incoming question. It uses `ANY` because a discovered mention
  need not repeat every word in the question.

## Traversal

The admitted starting parent is the first bounded context cloud. Every verified
reference binding in that parent remains an independent first-hop candidate.
Later transitions must renew question-derived pressure through the native
signed 6-1-6 context cloud. No expected path can promote a transition.

Pressure completion produces an evidence workspace and citations only. It does
not form textual answers, execute an operator capability, alter ranking, create
authority, invoke a model, or train a model.

## Failure

Missing ruling structure, missing admitted start evidence, invalid frontier,
fixed-point exhaustion, ambiguity, and traversal-budget exhaustion remain
explicit results. They must not be repaired with benchmark knowledge.
